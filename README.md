# Partner Extended Profile

Reusable Odoo 18 `res.partner` fields for personal/contact information that is not specific to REACT or any other organization.

Fields include date of birth, gender, alternate/work phone, employer, marital status and structured identity documents. Date of birth is validated centrally here so any dependent module gets the same rule: it must be before today.
